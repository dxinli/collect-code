# 项目简介

我们是智能灌溉设备厂商，现有 LoRaWAN 网关 MQ-SG40W，配套 LoRa 电动调节阀。需要开发网关侧边缘服务，对接 ChirpStack，完成 LoRa 节点数据上行、云端指令下行，同时对接 Modbus TCP，按照物模型做协议转换，通过 MQTT JSON 和我们云端对接。

优先使用 Go 语言开发。可以提供实物网关+阀门样品邮寄给开发者联调。

## 核心工作内容

1. ChirpStack v4 集成：打通 LoRa 上行、下行通道；确认下行调用接口，网关数据上云链路保留，不关闭 ChirpStack；
2. Modbus TCP 主站开发：读取/写入阀门 Modbus 寄存器，按照给定 Modbus 表做数据采集、下发；
3. 物模型映射：电动阀物模型（属性上报、服务下发、事件上报、超时机制），Modbus 数据 ↔ 云端标准 JSON 互转；
4. MQTT 客户端开发：网关和云端 MQTT 服务通信，上行推送 JSON 报文，订阅下行控制指令，转发给 LoRa/Modbus；
5. 基础异常处理：离线、超时、重发、简单日志；
6. 交付：完整源码、编译脚本、部署文档、报文示例、测试说明；
7. 配合我方做实物联调，修复上下行稳定性问题。

## 不需要做

- 云端后台页面、数据库；
- ChirpStack 底层源码修改（配置、集成、应用层对接即可）；
- 硬件驱动开发，网关硬件已经就绪。

## 必备技能要求，投递前请自查

- ✅ Linux 服务开发
- ✅ ChirpStack v4 对接经验（重点：LoRa 下行下发踩坑经验）
- ✅ MQTT 协议，JSON 报文开发
- ✅ Modbus TCP 主站开发经验
- ✅ Go 语言优先（熟悉 Python 也可以沟通）
- ✅ 有工业 IoT/智慧灌溉、传感器网关项目经验优先
- ✅ 有实物联调能力，支持接收硬件样品调试

1. 代码版本管理；

4. 自测：上行稳定上报、阀门开关下行指令可靠、超时逻辑正常。
