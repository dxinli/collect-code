# 测试策略与判据

本文件定义测试分层、可执行检查与数值判据。行为要求见 `docs/spec/spec.md`；外部报文见 `docs/contracts/external.md`。测试是这些契约的证据，不是第二份规范。

## 分层

| 层 | 范围 | 时间 | 依赖 | 运行时机 |
|---|---|---|---|---|
| L1 单元 | 内核组件：调度、状态、调用、转发、事件总线 | 假时钟 | 假驱动、假通道、假适配器、内存 Store | 每个 PR |
| L2 集成 | 驱动编解码、Store 两阶段、适配器、通道重连 | 假时钟（编解码可无时间） | 内存对端、真实 bbolt 临时目录、ChirpStack 桩 | 每个 PR |
| L3 端到端 | 真实二进制 + `simulate` + 内嵌 broker | 真实时钟 | 进程与端口 | nightly，30–60 分钟 |
| L4 发布门禁 | 真实二进制 + 真实时钟 | 真实 24 小时 | 专用 runner | v1.0 发布前人工执行 |

假时钟无法注入独立进程，因此 L3/L4 必须用真实时钟。“24 小时稳定性”不属于单 ticket 验收，它是发布门禁。

## 假时钟

- 内核与驱动构造时必须接收时间抽象；由 `scripts/check-time.sh` 静态检查直接调用与别名 import，不接受人工清单。
- 业务超时不得用运行时上下文截止时间；上下文只做取消传播。
- 测试必须提供可设当前时间、可推进、可触发到期 ticker/timer 的假时钟；所有样本时间必须由同一个假时钟产出。
- 必须确定性验证：相位不累积、missed tick 跳过、单设备截止时间放弃、服务超时窗口、缓存淘汰。

## bbolt 崩溃恢复

- 不用“写一半”或随机 kill 制造崩溃。bbolt 事务原子，崩溃窗口在两次事务之间。
- 必须测试：写入 `accepted` 后关闭（不写 `final`）→ 重开 → 查询仍为 `accepted` → 调用方对该 `seq` 回 `4004` 且不重放。
- fsync 耐久性用子进程自执行：写 `accepted` 后直接退出，父进程重开断言。该用例放 nightly，不进入每 PR 检查。
- 合同测试必须同时跑内存实现与 bbolt 实现；bbolt 用临时目录，测试结束清理。

## 模拟器

- RTU 从站走 RTU-over-TCP，零外部依赖；与生产 `modbus-rtu-tcp` 链路共用同一传输路径。串口 termios 与波特率留实物联调。
- 内嵌 MQTT broker 必须是纯 Go；`simulate` 自包含，不依赖 docker、apt 或系统服务。
- ChirpStack 桩必须是“迷你队列模拟器”，不是空壳：必须模拟 FIFO、`isPending`、`txack`/`ack` 时序，否则三种回执组合无法验证。
- 模拟器的从站与 broker 必须用独立客户端验证，不复用被测实现。

## 数值判据

- **L1（假时钟快进 24 小时，CI）**：60 秒周期 = 1440 tick；上报条数必须为 1440 ± 2；最大相邻间隔 ≤ 1.2×周期；无离线事件；无 `bad`/`stale`；计划时刻不累积漂移。
- **L3（真实时钟 30–60 分钟，nightly）**：无进程崩溃、无未处理错误日志；断线后能补发；真实 socket 与重连路径被覆盖。
- **L4（真实 24 小时，发布门禁）**：同 L3 判据；内存与状态库增长必须在预算内（常驻内存 ≤100 MB，状态库 ≤50 MB）。
- 真实抖动 ≤ ±10% 只在 L3/L4 判定；L1 只证明“不累积”，不得用 L1 结果声称真实抖动达标。

## 测试标注与追踪

测试必须在注释中标注覆盖的规范或合同锚点：

```text
// Covers: REQ-INVOKE-01, EXT-CODE-01
```

`docs/traceability.md` 必须为每个 `REQ-*` 与合同锚点记录 `covered`、`planned(ticket)` 或 `not-applicable`。CI 只失败于“既无归属也无计划”的条目，不把尚未实现的计划项当成失败。

健康与指标测试必须按 `REQ-OPS-02` 的固定指标名、类型与标签断言，不得只断言“计数器存在”。

## v0.1 的独立性前提

- 接口能力、命令状态与事件种类在 v0.1 就按全量定义；LoRa 只填不同的能力布尔与事件，不改接口。
- 唯一必须提前写对的是状态：新鲜观测必须同时接受读取与事件两个入口；离线与新鲜度参数全程配置驱动，不得按 Modbus 周期硬编码。
